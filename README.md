# The-Nature-of-Code
My c++ version of the examples in The Nature of Code by Daniel Shiffman, compiled using emscripten to webassembly to be viewable through a browser.

# Source Code
the source code will be available through the /src directory. I'm not worried about optimization when learning from this book, so there may be some ...interesting code.
